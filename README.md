# .github

デフォルトのコミュニティヘルスファイルおよび環境セットアップスクリプト。

## セットアップ方法

### 1. 環境変数ファイルの準備

`.env.example` をコピーして `.env` を作成し、各変数を設定します。
各変数の説明は `.env.example` 内のコメントを参照してください。

```bash
cp .env.example .env
# .env を編集して各変数を設定する
```

> **注意**: `.env` は機密情報を含むため `.gitignore` により Git 管理対象外です。
> 絶対にリポジトリにコミットしないでください。

### 2. セットアップスクリプトの実行

```bash
bash setup.sh
```

## ファイル構成

| ファイル | 説明 |
|---|---|
| `.env.example` | 環境変数のテンプレートファイル（変数の説明付き） |
| `.env` | 実際の環境変数ファイル（各自で作成・Git 管理対象外） |
| `setup.sh` | 環境変数を読み込んでセットアップを実行するスクリプト |
| `docs/deploy.md` | デプロイ手順書 |
